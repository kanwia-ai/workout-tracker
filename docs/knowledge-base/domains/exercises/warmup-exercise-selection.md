# Warmup exercise selection — which exercises actually warm up which muscles

## Claim

The most specific warmup for a working lift is **a sub-maximal version of the same lift**. The empty-bar squat warms up the squat better than any other exercise. The 30-second easy row warms up the row better than 10 minutes of foam rolling. This is the "S" in "specific warmup" and the foundation of ramp-set methodology (see [ramp-method](../warmup-recovery/ramp-method.md)).

**General warmup** (3-5 minutes of low-intensity cardio, dynamic stretching) addresses systemic readiness: body temperature, joint synovial fluid, baseline heart rate. **Specific warmup** (ramp sets of the working exercise) addresses the specific neural pattern, motor unit recruitment, and tissue load tolerance for that exercise.

The corollary: most "activation" exercises (band pull-aparts, glute bridges with band) do NOT warm up the working lift meaningfully — they are *additional movement*, not preparatory work. They have value as their own training stimulus but don't substitute for ramp sets of the working exercise.

## What warms up what

### Lower body — squat day

- **Squat pattern (back squat, goblet squat, leg press):**
  - Best warmup: empty-bar squat → bar + 30% → bar + 50% → bar + 70% (graduated ramp).
  - Secondary: 2-3 minutes easy cycling (general warmup).
  - **Backwards walking** (specifically mentioned by the trainer, philosophy doc §4) is acceptable as an "easy cardio" warmup specifically for squat days because it primes ankle dorsiflexion and quad eccentric without producing fatigue.
  - **NOT a good warmup for the squat:** band pull-aparts (target wrong muscles), foam rolling (no neural prep), static stretching (decrements force output — Behm & Chaouachi 2011 quantified ~5% strength reduction from pre-lift static stretch).
- **Hinge pattern (deadlift, RDL):**
  - Best warmup: empty-bar RDL → bar + 30% → bar + 50% → bar + 70%.
  - Secondary: kettlebell hip hinge with light load (`kettlebell_hip_hinge`) for hinge-pattern rehearsal if user is novice.
  - **Cat-cow** can be a useful spinal warmup specifically for deadlift days when the user has back stiffness.

### Upper body — push day

- **Horizontal push (bench, push-up, DB press):**
  - Best warmup: empty bar / very light DBs of the exact lift, 8-10 reps → 30% × 5 → 50% × 3.
  - Secondary: 1 set of push-ups (general upper-body warmup if first exercise of the day).
  - **Doorway pec stretch** (`doorway_pec_stretch`) is a *dynamic* stretch when done with sway, not a static hold — okay as part of general warmup; not enough on its own.
- **Vertical push (overhead press):**
  - Best warmup: empty bar OHP → 30% → 50% → 70%.
  - Secondary: arm circles, thoracic rotation (`ex-thoracic-rotation`) for joint prep.

### Upper body — pull day

- **Vertical pull (pull-up, lat pulldown):**
  - Best warmup: 1-2 lat pulldowns at 30-50% working weight. For a hard-to-feel lift like the pulldown, this is also the mind-muscle priming (see [mind-muscle-connection-research](mind-muscle-connection-research.md)).
  - Secondary: hanging passive stretch from the bar (5-10 seconds) for lat decompression.
  - **NOT enough:** band pull-aparts. They target rear delts / scapular retractors, not the lat-driven vertical pull.
- **Horizontal pull (row variants):**
  - Best warmup: empty bar / light DB row at 30-50% working weight.
  - Secondary: scap pull-ups or 5-10 second hangs.

### Glute-priority day

- **Hip thrust (main lift):**
  - Best warmup: bodyweight glute bridge → empty-bar hip thrust → bar + 30% → bar + 60%.
  - Secondary: clamshell (`banded_clamshell`) for glute med priming (low load, awareness-building — not muscle-fatiguing).
  - **The "activation" trap:** doing 3 sets of heavy clamshells before hip thrusts is *exhaustion*, not activation. Keep activation work low-load (1 set, 10-15 reps, RIR ≥5).

### Smaller / harder-to-feel lifts

- **Lateral raise:** 1 warmup set at half the working weight is usually sufficient.
- **Face pull:** 1 warmup set at 30% the working weight; the lever for face pulls is finding the contraction, not warming the muscle.
- **Curls / tricep extensions:** 1 warmup set if it's the first arm exercise; 0 sets if a compound has already warmed the synergists (chin-up warms up biceps; bench warms up triceps).

## The "activation" question

The fitness world has marketed activation drills (glute bridges, clamshells, band pull-aparts) as essential pre-lift work. The research is mixed:

- Crow 2012, Crooks 2018, and others have tested whether pre-lift glute activation drills meaningfully change EMG / performance on subsequent lifts. **Findings: equivocal.** Some studies show small short-term EMG changes that don't translate to performance improvements; others show nothing.
- The mechanism that *would* work — improved mind-muscle connection at the muscle being activated — is real (see [mind-muscle-connection-research](mind-muscle-connection-research.md)). But this is *learning a pattern*, not "waking up" a muscle. The muscle was never asleep.
- The myth `activation-exercises-recruit-muscles` covers this in detail.

**Practical position:** activation drills are useful for two specific purposes:
1. **Mind-muscle priming** for hard-to-feel exercises (see [hard-to-feel-exercises-catalog](hard-to-feel-exercises-catalog.md)). 1 light set, focus on contraction quality, not load.
2. **Joint mobility / pattern rehearsal** for users with limited ROM or skill (e.g., bodyweight squat warmup for a user learning the squat).

Activation is NOT a structural fix for "your glutes aren't firing" or any similar bro-science framing.

## Nuance

- **The empty-bar set DOES count.** Some lifters skip the empty bar on the bench press because it "feels too light." The bar is 45 lbs / 20 kg — that's real load for the rotator cuff and the spinal stabilizers. The empty-bar set rehearses the bar path, warms the joints, and primes the synergists.
- **Cardio warmup is a tool, not a substitute.** 3-5 minutes of bike / row / walk pre-lift is universally helpful (raises body temp, increases joint synovial fluid). It does NOT replace ramp sets — it's general warmup, not specific warmup.
- **Don't fatigue the muscle in warmup.** A "warmup set" is always 3+ reps in reserve. If a ramp set feels close to working effort, the lifter has miscalibrated — drop the reps or the load on the next ramp set.
- **Hard-to-feel exercises need MORE warmup, not different warmup.** Adding band pull-aparts before the lat pulldown doesn't help — the lat pulldown ramp sets ARE the warmup. The lat pulldown's warmup count just goes up (see [warmup-set-count](../warmup-recovery/warmup-set-count.md)).
- **Cold environments / early morning sessions add 1 ramp set across the board.** Body temperature is the lever.
- **First session back from a >7-day layoff adds 1 ramp set per main compound.** The motor pattern has cooled off; pattern rehearsal needs more iterations.

## What this contradicts

- **"Activation exercises wake up your glutes / your lats."** Muscles don't sleep. See myth `activation-exercises-recruit-muscles`.
- **"Foam rolling is a warmup."** Foam rolling is comfort / perceived-tightness management. It's not specific warmup for any lift. See `foam-rolling-honest` in the warmup-recovery domain.
- **"Static stretching warms up the muscle for lifting."** No — static stretching pre-lift decrements force output (~5% per Behm 2011). Save static stretching for cooldown. See `static-vs-dynamic-stretching` in warmup-recovery.

## Application in this app

- **Engine warmup-set emission:**
  - The variant pool's `ramp_style` field (`compound` / `accessory` / `none`) governs warmup-set count per lift.
  - `compound` → 2-3 ramp sets of the same exercise at increasing percentages.
  - `accessory` → 1 ramp set.
  - `none` → 0 ramp sets (the exercise IS the warmup — rehab primer / mobility / activation).
- **Cardio warmup (3-5 min easy)** is appended before the first compound when the user's session starts cold (no preceding warm activity).
- **Activation drills** appear in the warmup block ONLY for hard-to-feel exercises (see [hard-to-feel-exercises-catalog](hard-to-feel-exercises-catalog.md)) and ONLY at the awareness-building dose (1 set, RIR 5+, light load). Not as fatigue-producing pre-exhaust.
- **LLM nuance copy:**
  - "The first warmup set is also where you reconnect to the lats. Start at 50% of the working load and focus on driving the elbows down — that's the cue, not the bar path."
  - "We don't do band pull-aparts before the bench. The empty-bar set is the actual warmup; pull-aparts are training in their own right and don't prep the chest."
  - Do NOT say: "activation work wakes up dormant glutes" (myth); "static stretches prepare your muscles for lifting" (myth).
