# Rep ranges for maximal strength

## Claim

Maximal 1RM strength is best developed by training at **high relative loads (≥80% 1RM, typically 1–6 reps per set)**. Schoenfeld 2017's low- vs high-load meta-analysis found significantly larger strength gains for high-load training (1RM tests) despite equivalent hypertrophy. The Schoenfeld 2021 Re-Examination of the Repetition Continuum makes the same call: strength prefers heavy.

**Practical default for strength-focused programming on main lifts: 3–6 reps at 80–90% 1RM, 2–5 minutes rest, RIR 1–3.**

## Nuance

- **Strength gain is loading-specific** — practice with heavy loads teaches the nervous system to recruit high-threshold motor units and to execute the lift at maximal intent. Hypertrophy gains in 8–12 do contribute strength gain, but specifically heavy practice produces the biggest 1RM result.
- **Novices are an exception** — early-stage lifters gain strength readily across the rep continuum because nearly any near-failure stimulus drives adaptation. 5×5 at moderate load is a standard novice strength template (see Starting Strength, StrongLifts, GZCLP). The 1–6 rep prescription becomes more important as the user becomes intermediate/advanced.
- **CNS fatigue scales with load × proximity to failure.** Heavy work close to failure (3RM grinders) is expensive — high recovery cost. Most strength programming keeps RIR 1–3 on heavy work and reserves true 1-rep tests for cycle peaks or competition. Pure singles are practice / testing, not the backbone.
- **Higher-rep "strength work" is hypertrophy + strength.** 6–10 reps at 70–80% 1RM produces meaningful strength gain too, especially in early intermediates. The 3–6 prescription matters most when the user is already strong relative to bodyweight and needs to push 1RM specifically.
- **Equipment and joint tolerance.** A user with shoulder/spinal issues may not tolerate 90% 1RM bench/squat. In that case, "strength" is best pursued at 70–80% 1RM with longer rest and tight technique. Don't force heavy loads through joints that aren't ready.

## What this contradicts

- **"High reps build strength as well as low reps."** False for maximal (1RM) strength. True for muscle size. (Myth: `myth-high-reps-build-strength`.)
- **"You only need 5×5 forever."** True for the first 6–18 months. After that, mixed loading (heavy + moderate) and periodization beat fixed 5×5 (Grgic 2017; Williams 2017).

## Application in this app

- For **goal = get_strong / strength**: main lifts default to 3–6 reps at 80–90% 1RM, RIR 1–3, 180s rest. Accessories sit in the 6–10 rep range.
- For **goal = lean_and_strong**: weekly split main lifts into one heavy day (3–6) and one moderate day (6–10) on each pattern — see master synthesis "lean_and_strong" architecture table.
- For **goal = build_muscle**: include at least one heavy compound set per week per pattern (3–6 reps) for strength preservation even if hypertrophy is the focus — supports load progression that drives the hypertrophy backbone.
- For **novices on strength goal**: use 3×5 or 5×5 at moderate-to-heavy load (~75–85% 1RM) on main lifts with linear weekly progression. Don't prescribe 1–3 rep singles to a novice; technique is too unstable.
- LLM nuance layer: when justifying a heavy prescription, cite Schoenfeld 2017 (low vs high load meta — heavy wins on strength) and reference loading specificity. Do NOT claim "heavy reps build muscle better" — they build *strength* better; hypertrophy is equivalent when effort is matched.
